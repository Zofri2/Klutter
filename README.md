# Klutter
Klutter est un logiciel Windows gratuit pour les photographes qui ont des milliers de photos à parcourir : un tri rapide, des étoiles, des étiquettes couleur, un envoi en un clic vers tes dossiers, et un module de développement inspiré de Lightroom. Tout reste sur ton ordinateur. Tes fichiers originaux ne sont jamais modifiés.
